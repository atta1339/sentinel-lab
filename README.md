# Microsoft Sentinel Lab
A hands-on security engineering lab demonstrating Microsoft Sentinel configuration, analytics rules, hunting queries, automation workflows, workbooks, and incident triage. This project reflects real SOC/DFIR → Security Engineering work, including detection tuning, telemetry onboarding, automation, and investigation workflows.
---

## 📌 Overview

This repository contains:

- Data connectors
- Analytics rules
- Hunting queries (KQL)
- Workbooks
- Watchlists
- Automation (SOAR) playbooks
- Incident triage workflows
- Troubleshooting notes
- Screenshots of the lab environment

The goal is to demonstrate practical Sentinel engineering capability.

---

## 🧩 Architecture

**Azure Resources → Data Connectors → Sentinel Workspace → Analytics Rules → Incidents → Automation → Workbooks & Hunting**

Key components:

- **Data Connectors** bring in telemetry from Azure, Defender, Syslog, and other sources.
- **Analytics Rules** detect suspicious activity.
- **Hunting Queries** support threat hunting and investigation.
- **Workbooks** provide visual dashboards.
- **Automation Playbooks** enrich, tag, or close incidents.
- **Watchlists** store reference data.
- **Troubleshooting** ensures ingestion and detection reliability.
